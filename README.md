## Qué es

FerreiroTV es una app para **Android TV** (pensada para NVIDIA Shield) con perfiles, «Seguir viendo», sincronización con Trakt y un mando en el móvil para controlarla. Es de uso personal y familiar.

Este repositorio **solo contiene las versiones instaladas** (los archivos `.apk`). No tiene código fuente.

## Instalar

1. En la tele, activa la instalación de apps de orígenes desconocidos para la app con la que vayas a abrir el archivo (Ajustes → Seguridad y restricciones).
2. Descarga **`FerreiroTV.apk`** de la [última versión](https://github.com/Charlyiii/FerreiroTV-releases/releases/latest). Lo más cómodo es hacerlo con la app *Downloader* de la propia tele, escribiendo la dirección de la descarga.
3. Ábrelo y pulsa **Instalar**.
4. La primera vez, configura tus claves y perfiles (la app te guía con un asistente; también se puede hacer desde el móvil con el código QR).

## Actualizar

Una vez instalada, FerreiroTV se actualiza sola: mira si hay versión nueva al abrirse. También puedes comprobarlo a mano en **Ajustes → Actualizar**; solo hay que pulsar **Instalar** cuando Android lo pida.

> Las versiones de este repositorio están firmadas con mi clave. Si instalas un archivo de otro origen, no se podrá actualizar desde aquí.
